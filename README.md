## Description

This GitHub repository contains the code used to run the simulations described in our recent preprint:

**Error analysis of the complex-valued Kuramoto model**, Robin Delabays, Longfei Gao, and Tung T. Nguyen, preprint, 2026.

The repository includes functions for solving the original Kuramoto model and its complex-valued analogue. It also contains the network data used in our simulations.
